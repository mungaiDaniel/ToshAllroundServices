# Anleitung für Daniel: So pflegen Sie Ihre Website

Hallo Daniel! Mit dieser Anleitung ändern Sie Fotos, Öffnungszeiten, Texte und mehr – ganz ohne Technik-Wissen. Am besten benutzen Sie dafür Ihr Handy.

**Ihre Verwaltung finden Sie hier:** `toshallroundservices.de/admin`
(Tipp: Speichern Sie die Seite als Lesezeichen oder tippen Sie in Ihrem Browser auf „Zum Startbildschirm hinzufügen“, dann haben Sie ein Symbol wie bei einer App.)

> **Das Wichtigste vorweg:** Alles, was Sie speichern, ist **sofort auf der Website**. Wenn Sie etwas nur ausprobieren möchten, verstecken Sie es mit dem **Auge-Symbol**. Gelöscht wird immer erst nach einer Rückfrage.

Diese Anleitung steht auch in der Verwaltung selbst: unten auf **„Mehr“** und dann **„Hilfe“** tippen.

---

## 1. So melden Sie sich an

1. Öffnen Sie im Browser Ihres Handys `toshallroundservices.de/admin`.
2. Geben Sie Ihre **E-Mail-Adresse** und Ihr **Passwort** ein und tippen Sie auf **„Anmelden“**.
3. Sie bleiben **auf diesem Handy angemeldet**. Erst wenn Sie selbst auf **„Abmelden“** tippen (unter „Mehr“ oder in den „Einstellungen“), müssen Sie sich wieder anmelden.
4. **Passwort vergessen?** Tippen Sie auf der Anmeldeseite auf **„Passwort vergessen?“**. Sie bekommen eine E-Mail mit einem Link, über den Sie ein neues Passwort wählen. Schauen Sie auch im Spam-Ordner nach.

**Passwort ändern:** Mehr → **Einstellungen** → „Passwort ändern“ (mindestens 8 Zeichen).

---

## 2. Fotos hinzufügen

1. Tippen Sie unten auf **„Galerie“** und dann auf **„Fotos hinzufügen“**.
   (Auf der Startseite der Verwaltung geht es auch mit dem Knopf **„Foto hinzufügen“**.)
2. Wählen Sie **„Aus der Galerie wählen“** (Sie können mehrere Fotos auf einmal auswählen) oder **„Foto aufnehmen“** für die Kamera.
3. Wählen Sie für jedes Foto die **Kategorie** (z. B. Büros) und schreiben Sie, wenn Sie möchten, eine **kurze Beschreibung**.
4. Mit dem Schalter **„Auf der Startseite zeigen“** erscheint das Foto auch auf der Startseite.
5. Tippen Sie auf **„Hochladen“**. Die Fotos werden automatisch verkleinert und sind sofort auf der Website.

**Reihenfolge ändern:** Halten Sie den **Griff** (die sechs Punkte oben links am Foto) fest und ziehen Sie das Foto an eine andere Stelle.

**Foto verstecken:** Tippen Sie auf das **Auge**. Tippen Sie noch einmal, dann ist das Foto wieder sichtbar.

**Foto bearbeiten:** Tippen Sie auf **„Bearbeiten“**. Dort ändern Sie Kategorie, Beschreibung, Bildausschnitt und mehr – und tippen auf „Speichern“.

**Foto löschen:** „Bearbeiten“ → **„Löschen“**. Das Foto liegt dann **30 Tage im Papierkorb** (Reiter „Papierkorb“) und kann dort mit **„Wiederherstellen“** zurückgeholt werden. Nach 30 Tagen ist es endgültig weg.

**Vorher/Nachher:** Tippen Sie auf **„Vorher/Nachher erstellen“**, wählen Sie zuerst das „Vorher“-Foto, dann das „Nachher“-Foto. Auf der Website sehen Besucher die beiden mit einem Schieberegler.

---

## 3. Öffnungszeiten ändern

1. Tippen Sie unten auf **„Mehr“** und dann auf **„Kontaktdaten & Öffnungszeiten“**.
2. Bei jedem Wochentag: Schalter **an** = geöffnet, Schalter **aus** = geschlossen. Dann „von“ und „bis“ einstellen.
3. Mit **„Montag für Di–Fr übernehmen“** geht es schneller, wenn die Zeiten gleich sind.
4. Tippen Sie unten auf **„Speichern“**. Die neuen Zeiten sind sofort auf der Website.

Hier können Sie auch **Telefon, WhatsApp, E-Mail und Adresse** ändern. Die WhatsApp-Nummer bitte mit Ländervorwahl eingeben, z. B. `+49 176 12345678`.

---

## 4. Ankündigung einschalten

Für Hinweise wie *„Vom 24. bis 31. Dezember geschlossen“*. Der Hinweis erscheint oben auf jeder Seite.

1. Tippen Sie auf der Startseite der Verwaltung auf **„Ankündigung“**.
   (Oder: Mehr → Kontaktdaten & Öffnungszeiten, nach unten scrollen.)
2. Schalten Sie **„Ankündigung anzeigen“** ein.
3. Schreiben Sie den Text auf **Deutsch**. Englisch ist freiwillig. Darunter sehen Sie die **Vorschau**, so wie Besucher es sehen.
4. Tippen Sie auf **„Speichern“**.

**Ausschalten:** Schalter wieder aus und **„Speichern“**. Der Text bleibt für das nächste Mal erhalten.

---

## 5. Nachrichten lesen und beantworten

1. Tippen Sie unten auf **„Post“**. Eine **rote Zahl** zeigt, wie viele Nachrichten neu sind. Neue Nachrichten sind **blau markiert**.
2. Tippen Sie auf eine Nachricht, um sie ganz zu lesen. Sie gilt dann als **gelesen**.
3. Antworten Sie mit **einem Tipp**:
   - **WhatsApp** – öffnet WhatsApp mit einer freundlichen Begrüßung,
   - **Anrufen** – ruft die Nummer an,
   - **E-Mail** – öffnet Ihr E-Mail-Programm.

   (WhatsApp und Anrufen gibt es nur, wenn die Person eine Telefonnummer angegeben hat.)
4. **„Als ungelesen markieren“** erinnert Sie später daran. **„Löschen“** entfernt die Nachricht (Sie werden vorher gefragt).

Anfragen aus dem Kontaktformular kommen **zusätzlich per E-Mail** bei Ihnen an. Nachrichten in der Verwaltung werden nach 12 Monaten automatisch gelöscht.

---

## 5a. Aktivität: Was passiert auf der Website?

1. Tippen Sie unten auf **„Mehr“** und dann auf **„Aktivität“**.
2. Oben wählen Sie **7, 30 oder 90 Tage**.
3. Sie sehen: **Besuche**, **Seitenaufrufe**, **Kontakt-Taps** (WhatsApp, Anruf, E-Mail) und **Nachrichten** aus dem Formular. Der Pfeil vergleicht mit dem Zeitraum davor.
4. Darunter: Besuche pro Tag, beliebteste Seiten, Aktionen, Herkunft der Besucher sowie Gerät und Sprache.

Es werden nur **anonyme Tageszahlen** gezählt (keine Personen, keine IP-Adressen, keine Cookies). Wer „Do Not Track“ aktiviert hat, wird nicht gezählt.

## 6. Weitere Bereiche in Kürze

| Bereich | Wofür? |
| --- | --- |
| **Leistungen** | Texte, Aufzählungspunkte, „ab“-Preis und Foto Ihrer Leistungen ändern, neue Leistung anlegen, Reihenfolge festlegen. Unter dem Feld sehen Sie, wie viele Zeichen noch erlaubt sind. |
| **Texte** | Überschrift, Slogan, „Über uns“ und Ihr Profil – Deutsch und Englisch nebeneinander. „Original“ holt den ursprünglichen Text zurück. |
| **Bewertungen** | Kundenstimmen mit Sternen eintragen. Sobald eine Bewertung sichtbar ist, erscheint auf der Startseite ein Bewertungs-Bereich. Bitte nur echte Bewertungen mit Einverständnis der Kunden. |
| **Qualifikationen & Lebenslauf** | Zeugnisse als Foto oder PDF hochladen, Stationen Ihres Lebenslaufs pflegen, den Lebenslauf als PDF austauschen. |
| **Einstellungen** | Passwort ändern, Sprache der Verwaltung (Deutsch/English), Abmelden. |

**Das „?“-Symbol** neben jeder Überschrift erklärt Ihnen den Bereich in einem Satz.

**Website ansehen:** Der Knopf oben rechts (Pfeil-Symbol) bzw. „Website ansehen“ öffnet Ihre Website in einem neuen Tab.

---

## Wenn etwas nicht klappt

- **„Keine Internetverbindung“:** Prüfen Sie WLAN/Mobilfunk und tippen Sie noch einmal auf „Speichern“. Ihre Eingaben bleiben stehen.
- **„Nicht gespeicherte Änderungen“:** Sie haben etwas geändert, aber noch nicht gespeichert. Tippen Sie unten auf **„Speichern“** – oder auf „Verwerfen“, wenn Sie die Änderung nicht möchten.
- **Eine Änderung ist nicht zu sehen:** Laden Sie die Website neu (Seite nach unten ziehen). Neue Inhalte erscheinen nach spätestens einem Moment.
- **Alles andere:** Melden Sie sich bei Ihrem Webdesigner.
